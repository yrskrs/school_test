# SchoolTest 1.6.8 — інтерфейс і навантаження, 20.10.2026

## Базовий план і виконані зміни

1. Перевірити підрахунок питань. Форма входу та `/api/session-roster` використовували весь банк. Додано спільний SQL-підрахунок загальної кількості та вибірки з урахуванням виключених тем і ліміту. Картка показує «Усього в тесті: 200» / «Буде задано: 25» у готовій формі, після введення коду, у закріпленій сесії та після помилки входу. Старе поле API `question_count` зберігає значення всього банку; нове `assigned_question_count` містить кількість для проходження. Інструкція продовженої спроби використовує вже призначені питання.
2. Додати масштаб і адаптивність. Кнопки − / відсоток / + працюють на всіх сторінках у межах 60–150%; натискання відсотка скидає 100%. Вибір зберігається локально та застосовується до відображення до появи вмісту. Якщо сховище заблоковане, керування продовжує працювати. Панелі, кнопки, статистика, сітки, графіки й довгі адреси переносяться; на малих/низьких екранах верхня панель тесту прокручується. Модальні вікна враховують масштаб. Довгі питання прокручуються без обрізання.
3. Виправити тему. У тесті залишено SVG сонця/місяця з доступною назвою. Зміна теми працює без localStorage; синхронізовано колір тексту.
4. Скоротити зайву роботу. Готова форма не повторює запит списку. Введення коду об'єднується за 300 мс, застарілі запити скасовуються, надсилання під час перевірки блокується. Підрахунок не завантажує тексти/варіанти всіх питань. Моніторинг завантажує відповіді пакетно без текстів питань, об'єднує одночасні HTTP-оновлення й залишає один heartbeat після перепідключення. Прибрано постійну анімацію індикатора з'єднання; враховано системне зменшення руху. Резервне опитування, правила повного екрана, офлайн-черга, оцінювання й збереження відповідей працюють як раніше.
5. Провести регресію, перевірки Chromium/PostgreSQL, записати результати, зібрати Docker, зберегти коміти та відправити в GitHub.

Під час браузерного аудиту також усунуто помилку профілю звичайного вчителя: обробник адміністративної форми більше не викликається для відсутнього елемента.
