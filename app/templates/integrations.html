Як працює взаємодія з журналом

📖 Довідник API та специфікація v2 ↓
1. Створіть ключ API
Задайте зрозумілу назву (наприклад, «Журнал 7-А») та додайте опис призначення, щоб легко розрізняти підключення.
2. Вставте адресу й ключ у журнал
У журналі відкрийте «Підключити тести / завдання» та вставте скопійовану адресу цього сайту й секретний ключ.
3. Авто-синхронізація та моніторинг
Журнал передасть списки учнів сюди, а готові оцінки завантажуватимуться в журнал за кліком. Уся статистика запитів фіксується нижче.

Той самий ключ дозволяє журналу передати сюди копію класу та учнів. Список залишається у власній базі тестів; учні вибирають імена без службових ID. Якщо дитини немає у списку, вона може ввести ім’я самостійно — її результат збережеться в «Позакласних учнях» журналу до рішення вчителя.

Документація та взаємодія з API (School API v2)

SchoolTest надає уніфікований REST API контракт версії 2 для безпечного обміну списками та оцінками з електронним журналом.

🔑 Автентифікація

Усі запити до API повинні містити HTTP-заголовок Authorization: Bearer <ВАШ_КЛЮЧ_API>. Ключ створюється вчителем і прив'язується до його профілю. Доступ мають лише сесії та тести цього вчителя.

📡 Основні маршрути (Endpoints)

GET /api/v2/journal/roster/
Повертає списки класів, предметів та учнів учителя для вибору в журналі. Додає позначку journal_roster_import.
POST /api/v2/journal/roster/
Приймає копію списку учнів із журналу. Створює або оновлює локальні записи класу та учнів без видалення наявних даних.
GET /api/v2/journal/grades/?class_id=&subject_id=&date_from=&date_to=&cursor=0
Повертає оцінки учнів за вибраний період для конкретного класу та предмета. Підтримує курсорну пагінацію до 500 записів на сторінку.

💡 Поради та типові запитання

  • Зміна IP-адреси (школа / дім): Ключ API прив'язаний до бази сайту, а не до IP-адреси. Якщо ви змінили мережу, просто оновіть IP-адресу сайту в журналі — сам ключ змінювати не потрібно.
  • Тимчасова пауза: Якщо ви хочете тимчасово заблокувати запити журналу (наприклад, під час канікул або редагування тестів), натисніть «⏸ На паузу». Журнал отримуватиме зрозумілу відповідь 401, а спроби запитів фіксуватимуться в лічильнику.
  • Ротація ключа: Якщо ключ потрапив до сторонніх осіб, відкрийте «✏️ Редагувати» та оберіть «Згенерувати новий секретний токен». Попередній токен негайно анулюється, а ID та історія статистики збережуться.
Підготовка класів, предметів і попередніх результатів

Якщо тест ще не має класу чи предмета, виберіть їх для сесії нижче. Попередній результат без учня зі списку прив’яжіть до потрібного імені. Так зберігається його належність; однакові імена не об’єднуються автоматично.
