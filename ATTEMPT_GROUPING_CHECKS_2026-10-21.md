# Групування спроб і зручність моніторингу — 2026-10-21

## Знайдені проблеми

1. Шаблон моніторингу показує номер спроби поруч з іменем, а автооновлення вставляє ще одну позначку всередину імені. Це дублювання відображення, а не доказ дублювання записів БД.
2. Моніторинг не групує завершені спроби й не впорядковує поточні перед історією. Нові учні не отримують картку в мобільному вигляді; видалені на іншому екрані рядки залишаються до перезавантаження.
3. Нумерація моніторингу використовує лише ім’я та може змішувати тезок. Результати не групують старі спроби без сталого ID, а деталі роботи шукають історію лише за іменем.
4. Для кнопок результатів виділено 9% фіксованої таблиці, а `overflow-wrap:anywhere` дозволяє переносити кожну літеру. Старі перевірки ширини сторінки цього не виявляють.
5. Код, копіювання й статус сесії розділені на різні рядки без чіткої структури. Сортування сесій та поточних спроб не можна вибрати.

## План

1. Зберегти попередній завершений редизайн окремим комітом; звірити GitHub.
2. Відтворити дублювання та вертикальні написи в Chromium на окремій PostgreSQL із вигаданими даними.
3. Узгодити визначення учня та нумерацію в API, моніторингу, результатах і деталях. Сталі ID мають пріоритет; для старих записів обмежити групування тією самою сесією та нормалізованим ім’ям.
4. Групувати тільки завершену історію; залишати всі поточні спроби окремо зверху. Додати вибір сортування, збереження розгорнутих груп та коректне повторне оновлення.
5. Дати діям достатню ширину, прибрати перенесення літер; впорядкувати код і статус сесії та додати сортування списку.
6. Перевірити повторні HTTP/WS-оновлення, завершення, приєднання й видалення, тезок, старі записи, фільтри, пагінацію, теми й масштаби.
7. Оновити версію та інструкції, зробити коміти, зібрати Docker, застосувати з резервною копією та опублікувати в GitHub.

## Фактичні результати

- GitHub звірено перед змінами й повторно перед публікацією: віддалений `main` залишався на `3be0ac3`. Попередній перевірений редизайн 1.6.13 збережено окремим комітом `6090b20`.
- [Відтворення на 1.6.13](reports/attempt_groups_2026-10-21/before.json): після оновлення кожен із п’яти перевірених рядків має дві позначки номера; «Спроби (2)» займає 10 рядків, «Краща» — 5. Записи БД під час цієї перевірки не дублювалися.
- Реалізовано всі пункти 3–5 плану. Завершення (`finished`, `timeout`, `stopped`) переносить спробу в історію; нерозпочаті, активні та призупинені залишаються зверху. Групи розгортаються кнопкою з `aria-expanded`, збереження стану працює при оновленні.
- Старі спроби об’єднуються за регістронезалежним ім’ям із нормалізованими пробілами лише всередині сесії. Сталі різні ID не змішуються. Історія в деталях використовує ті самі правила; SQL обмежує кандидатів відповідним ID або сесією.
- Виправлено також напис «Не розпочато» для одиночної зупиненої роботи: тепер «Зупинено» в обох видах результатів. Поле пошуку більше не стискається у вузький вертикальний стовпець на проміжній ширині.
- Python: **152/152** тестів застосунку, **22/22** синхронізації; п’ять нових сценаріїв додатково пройшли в **Docker/Python 3.11/PostgreSQL**. Перевірено тезок, зміну імені при тому самому ID, старі записи, архів, завершені статуси, сортування й пріоритет до пагінації.
- JavaScript: **31 сценарій учня**, синтаксис **8 скриптів**, повторне перепідключення та об’єднання паралельних запитів моніторингу проходять.
- [Окремий браузерний звіт](reports/attempt_groups_2026-10-21/checks.json): **127 перевірок розкладок**, 0 помилок JS. 1440/1366/1024/800/768/390/320 px, масштаби 80/100/120%, обидві теми; кнопки в рядках мають один текстовий рядок. Перевірено й розгорнуту історію результатів.
- Через справжні HTTP/WS перевірено **15 повторних оновлень**, одну позначку й рядок на спробу, завершення з негайним групуванням, повторні події зупинки без завищення лічильника, збереження сортування та розгорнутих груп. Вхід нового учня створює рядок і мобільну картку; видалення з іншої вкладки прибирає обидва без перезавантаження.
- [Повторний аудит усього кабінету](reports/attempt_groups_2026-10-21/workspace-checks.json): **721 перевірка розкладок**, 0 виходів за межі екрана, 0 помилок JavaScript, 0 зовнішніх HTTP-запитів; звичайний учитель, адміністратор, порожній профіль, обидві теми, взаємодії.
- Знімки комп’ютера й телефона оглянуто вручну. У звітах є лише вигадані навчальні дані. Робочі спроби не видалялися й не об’єднувалися у БД; зміни стосуються представлення.
