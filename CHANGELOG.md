# Історія змін ШколярТест

## 1.3.1 — 2026-10-10

- Учнівські списки показують лише імена. Стабільні ID залишаються всередині форми для правильного прив’язування результатів.
- Вибір імені більше не обрізає його за службовим роздільником; API v1/v2 та інтеграція сумісні з 1.3.0.
- Додано підказку до `scripts/update.sh` та оновлено документацію щодо початкового розгортання (`docker compose up -d --build`), якщо контейнер ще не створено.
- Оновлено опис версії, документацію та тег Docker-образу.

## 1.3.0 — 2026-10-10

- Постійні локальні класи, учні та предмети; рівноправний API v2 списків із повторними спробами і ручними конфліктами.
- Явні ID учнів, контекст сесії та зіставлення старих спроб; історія і чинні повторні спроби збережені.
- Ключі експорту власних остаточних оцінок. Журнал імпортує за кнопкою, без зміни шкали.
- Довідка, контракт API, окрема Docker-мережа та версія образу 1.3.0.


## 1.2.0 — 2026-10-04

- На панелі вчителя показано поточну версію й короткий опис оновлення; додано сторінку «Версія та можливості для вчителя» з описом імпорту, редактора, сесій, оцінювання та результатів. Посилання доступне внизу сторінок вчителя.
- Додано прямий імпорт MyTestX 10.2 (`.mtf`) у меню тестів і на панелі вчителя: перетворення виконується на сервері без Windows, Wine або запуску EXE.
- Підтримуються вибір відповідей, послідовності, відповідності, текстові й точні числові відповіді, області на зображеннях; зберігаються теми, бали та растрові зображення, зокрема DIB у RTF/WMF.
- Непідтримувані або пошкоджені файли повертають пояснення помилки замість імпорту з пропущеними питаннями. Ліміти: 20 МБ для MTF, 100 МБ після розпакування.
- XML-імпорт тепер читає `InputText`, `InputNum` і `TestOptions/Title`. Для короткої відповіді можна зберігати й редагувати кілька прийнятних відповідей; оцінювання враховує кожну.
- Зображення у відповідностях і текстових варіантах показуються в редакторі, учнівському тесті та перегляді відповідностей у результатах.
- Додано синтетичні перевірки конвертації, завантаження MTF через HTTP, збереження зображень, правильних відповідей та відхилення невірних файлів.

## 1.1.2 — 2026-10-04

- Виправлено падіння запуску PostgreSQL: додано `psycopg[binary]` для URL без явного драйвера в SQLAlchemy 2.1; підтримка `psycopg2` збережена.
- Обмежено SQLAlchemy перевіреними гілками 2.0/2.1 (`<2.2`).
- Docker-збірка перевіряє імпорт обох PostgreSQL-драйверів, застосунку та шаблонів до розгортання; перевірка використовує вигадані URL без підключення до БД.
- Виправлено стартове додавання старих колонок: перевірка наявності, окремі транзакції та PostgreSQL-сумісний Boolean default; PostgreSQL URL більше не трактується як шлях каталогу.
- При невдалій готовності update/restore автоматично показують логи контейнера.
- Додано ізольований Docker/PostgreSQL тест реального HTTP-запуску, збереження відповіді та зупинки після третього порушення.

## 1.1.1 — 2026-10-04

- Виправлено облік виходів із повноекранного режиму через Esc: обробка фактичної зміни стану, резервна перевірка та скидання попередження після повернення.
- Третє порушення зупиняє конкретну спробу на сервері зі статусом `stopped`. Облік події, оцінювання та зупинка записуються однією транзакцією; повторні запити не збільшують лічильник.
- Збережено облік виходів офлайн, локальну заборону продовження після третього та доставку журналу після відновлення зв’язку. Непідтверджені чернетки не видаляються.
- Розширено журнал дій учня та повідомлення моніторингу; автоматична зупинка відрізняється від зупинки вчителем.
- Додано видиму версію сайту, `/api/version`, `X-App-Version` та єдине версіонування адрес CSS/JS.
- Додано перевірки послідовних виходів, дублювання подій браузера, повернення зовнішнім керуванням, пропущеної події, офлайн/reload та зупинки на сервері.
