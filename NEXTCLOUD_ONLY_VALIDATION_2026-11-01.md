# SchoolTest 1.8.1 — резервування лише через Nextcloud

## Зміна

З резервування прибрано Google Drive, його поля ключів, OAuth-кнопку та callback. Доступний Nextcloud. Прямі запити й застарілі Google-завдання блокуються до звернення в мережу; старі Google-розклади вимикаються. Ядро цієї політики однакове зі SchoolWork 4.7.2.

Збережено особисті й адміністративні копії, ZIP, інкрементальні блоки, пароль, розклад, пошук, перевірку та відновлення. Наявні дані тестування, історія й архіви не видаляються. Міграцій БД немає. Старий Google-профіль потребує явного збереження підключення Nextcloud; Google-ключі не показуються в HTML/status API й прибираються під час збереження Nextcloud.

## Перевірка

Локально пройшли 35 тестів ядра, транспорту й стабільних блоків записів. Окремі сценарії HTTP перевіряють відсутність Google-контролів, callback 404, відхилення save/oauth/connect, приховування старих ключів і збереження Nextcloud. Тест повного відновлення посилено порівнянням усіх експортованих записів до/після відновлення.

Повні перевірки кандидатного образу, установлення та публікацію в GitHub буде записано після виконання.
