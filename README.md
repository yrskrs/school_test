# 🎓 SchoolTest (ШколярТест) — Автономна система шкільного тестування

> **Повністю автономна, сучасна система для створення, проведення та аналізу тестування знань учнів у школі.**  
> Працює в локальній мережі без інтернету. Включає веб-платформу (FastAPI) та графічний GUI менеджер (PyQt6).

---

## 🚀 Основні можливості (Feature Set)

### 📝 1. Підтримка 6+ типів питань
- **Одиночний вибір (`single_choice`)**: класичний вибір 1 правильного варіанта.
- **Множинний вибір (`multiple_choice`)**: вибір кількох правильних варіантів відповідей.
- **Вірно / Невірно (`true_false`)**: швидка оцінка тверджень.
- **Коротка текстова відповідь (`short_text`)**: введення слова або числа з нечітким порівнянням (Fuzzy Matching / Левенштейна) та нормалізацією пробілів і регістру.
- **Встановлення відповідностей (`matching`)**: інтерактивне з'єднання лівої та правої колонок (Drag & Drop та спадні списки).
- **Встановлення послідовності (`sequence`)**: зручне сортування етапів чи подій за порядком.
- **Графічні питання та вибір зображень (`image_choice` / `hotspot`)**: додавання ілюстрацій до тексту питань та варіантів.

### 📥 2. Універсальний імпорт тестів
- **Імпорт із Microsoft Word (`.docx`)**: автоматичне розпізнавання питань, варіантів відповідей, виділених правильних варіантів (зелений колір / жирний шрифт) та завантажених зображень.
- **Імпорт MyTestX XML (`.xml`)**: повна сумісність із популярним шкільним форматом MyTestX (розпізнавання розділів, питань та варіантів).
- **Імпорт та експорт у JSON**: швидкий обмін тестами між викладачами та різними ПК.

### 🔍 3. Інтелектуальна перевірка та Вікно аналізу помилок у тестах
- **Динамічний аналіз у реальному часі**: виявлення повторень варіантів відповідей у межах одного питання.
- **Модальне вікно `🔍 Вікно помилок`**: швидкий фільтр за типами помилок, пошук, кнопки **«🎯 Перейти до питання»** (з підсвічуванням та плавним скролом) та **«🗑️ Видалити це питання»** (із підтримкою скасування дії через `Ctrl+Z`).
- **Наочні підказки**: яскравий баннер прямо всередині картки питання вчителя.

### 🎨 4. Динамічне оформлення та перемикач теми
- **Сучасний дизайн (Glassmorphism & Vibrant Palette)**: адаптоване оформлення для будь-якої роздільної здатності.
- **Перемикач теми (Light / Dark Mode)**: стильна кругла плаваюча кнопка у правому верхньому кутку на всіх сторінках вчителя та учня з динамічною зміною вигляду.
- **Індикатор завантаження (`TopLoader`)**: плавний верхній прогрес-бар при збереженні та навігації між сторінками.

### 📡 5. Моніторинг у реальному часі (WebSocket)
- **Монітор проходження**: викладач бачить прогрес учнів у реальному часі (зелені/червоні квадратики відповідей, статус та бали).
- **Керування сесією**: можливість ставити на паузу, відновлювати чи достроково завершувати тест для окремого учня або всього класу.

### 🛡️ 6. Захист від списування та Безпека
- Контроль повноекранного режиму (виявлення перемикання вкладок/вікон).
- Блокування копіювання тексту та виділення.
- Перемішування питань та варіантів відповідей.
- Логування подій браузера (відкриття/закриття, втрата фокусу).

## 🛠️ Стек технологій

| Компонент | Технологія |
|-----------|------------|
| **Backend** | Python 3.11+, FastAPI, Uvicorn |
| **GUI Manager** | PyQt6 (Server Manager + Реєстрація) |
| **База даних** | SQLite3 (SQLAlchemy 2.0, режим WAL) |

| **Real-time** | WebSockets (FastAPI websockets) |
| **Безпека** | PBKDF2-HMAC-SHA256, HTTP-Only Signed Cookies |

## 💻 Запуск системи

### 🔹 На Windows:

1. **Автоматичне налаштування середовища**:
   Запустіть `setup_env.bat` (автоматично створить `.venv` та встановить усі бібліотеки).
2. **Запуск графічної панелі керування**:
   Запустіть `run_gui.bat` або `start_windows.bat`.
3. **Вікно реєстрації користувачів**:
   Запустіть `start_register.bat` або натисніть кнопку **«👥 Користувачі / Реєстрація»** у головному GUI вікні.

### 🔹 На Linux:

1. **Запуск сервера**:
   ```bash
   chmod +x start_linux.sh
   ./start_linux.sh
   # або вручну:
   python3 run.py
   ```
2. **Запуск вікна реєстрації (PyQt6)**:
   ```bash
   python3 run_register.py
   # або:
   ./start_register.sh
   ```

## 🔑 Перший запуск та створення адміністратора

При першому запуску сервісу, якщо в базі даних ще немає жодного користувача:
1. **Веб-майстер початкового налаштування (`/setup`)**:
   - Перейдіть у браузері за адресою `http://localhost:8000/` (або `http://localhost:8080/` у Docker).
   - Система автоматично перенаправить вас на сторінку **`/setup`** для створення головного облікового запису адміністратора.
   - Вкажіть ПІБ, логін, надійний пароль, предмет та класи.
   - За бажанням відмітьте чекбокс **«Завантажити зразковий тест»** для швидкого ознайомлення з можливостями.
   - Після створення адміністратора сторінка `/setup` блокується з міркувань безпеки.
2. **Через графічне вікно реєстрації (PyQt6)**:
   - Запустіть `start_register.bat` (Windows) або `python3 run_register.py` (Linux).
   - Створюйте та редагуйте облікові записи вчителів безпосередньо у зручній таблиці.

## 🐳 Розгортання з Docker та PostgreSQL (Production)

Для розгортання в production-середовищі рекомендується використовувати Docker. Це забезпечує ізоляцію, легке оновлення, резервне копіювання та перенесення між серверами. У цьому режимі замість SQLite використовується **PostgreSQL**.

### Вимоги

На сервері або ПК мають бути встановлені:
- [Docker](https://docs.docker.com/get-docker/)
- [Docker Compose](https://docs.docker.com/compose/install/)

### Покрокове розгортання

1. **Клонуйте репозиторій з GitHub**:
   ```bash
   git clone https://github.com/yrskrs/school_test.git
   cd school_test
   ```

2. **Створіть файл конфігурації `.env`**:
   ```bash
   cp .env.example .env
   ```

3. **Налаштуйте параметри у `.env`**:
   Відкрийте `.env` у текстовому редакторі (`nano .env`) та задайте:
   - `APP_PORT` — зовнішній порт веб-сервера (за замовчуванням `8000`).
   - `POSTGRES_PASSWORD` — надійний пароль для бази даних.
   - `DATABASE_URL` — оновіть пароль відповідно до `POSTGRES_PASSWORD`.
   - `SECRET_KEY` — згенеруйте випадковий секретний ключ для підпису сесій.

4. **Запустіть систему в Docker**:
   ```bash
   docker compose up -d --build
   ```

5. **Перевірте стан контейнерів**:
   ```bash
   docker compose ps
   ```

6. **Початкове налаштування в браузері**:
   - Відкрийте `http://<IP_АДРЕСА_СЕРВЕРА>:8000/` (або вказаний `APP_PORT`).
   - Система автоматично перенаправить вас на **`/setup`** для створення облікового запису адміністратора.

> [!NOTE]
> База даних PostgreSQL працює в окремому контейнері `postgres`. Всі її дані зберігаються у Docker-томі `postgres_data`. Файли користувачів (тести, результати, завантажені зображення) зберігаються у томах `app_data` та `app_uploads`. Це гарантує збереження ваших даних навіть при видаленні контейнерів!

### 💾 Резервне копіювання (Backup)

Для створення повної резервної копії системи (БД + файли) запустіть скрипт:
```bash
./scripts/backup.sh
```
Бекап буде збережено у папці `backups/` з поточною датою та часом (напр. `backups/2026-08-31_21-00-00/`).

### 🔄 Відновлення (Restore)

> [!WARNING]
> Відновлення повністю перезапише поточну БД та файли.

Для відновлення з існуючого бекапу вкажіть шлях до нього:
```bash
./scripts/restore.sh backups/2026-08-31_21-00-00
```
Скрипт автоматично зупинить застосунок, відновить БД та файли, а потім знову його запустить.

### 🚀 Оновлення системи (Update)

Для безпечного оновлення до нової версії (з автоматичним бекапом):
```bash
./scripts/update.sh
```
Оновлення НЕ призведе до втрати бази даних чи файлів. Код застосунку буде оновлено, але всі збережені дані залишаться в томах.

### ⏪ Повернення до попередньої версії (Rollback)

Якщо після оновлення виникли проблеми, ви можете відновити систему до стану перед оновленням за допомогою скрипта відновлення, використовуючи автоматичний бекап, який було створено під час виконання `update.sh`.

---

### 🚚 Перенесення на інший сервер / ПК

Систему можна легко перенести на інший комп'ютер без втрати даних:

1. На **старому ПК** створіть свіжий бекап: `./scripts/backup.sh`
2. Перенесіть на **новий ПК** наступні файли та папки:
   - Файли конфігурації: `compose.yaml`, `Dockerfile`, `.dockerignore`, `.env`
   - Папку зі скриптами: `scripts/`
   - Папку з бекапом: `backups/ВАШ_БЕКАП/`
3. На **новому ПК** відновіть систему:
   ```bash
   # Спочатку запустіть базу даних
   docker compose up -d postgres
   # Зачекайте 10 секунд для ініціалізації
   sleep 10
   # Відновіть дані
   ./scripts/restore.sh backups/ВАШ_БЕКАП
   ```

### 🔀 Міграція з існуючої SQLite на PostgreSQL

Якщо ви раніше користувалися системою через локальний SQLite і хочете перейти на Docker + PostgreSQL без втрати даних, виконайте наступні кроки:

1. Запустіть інфраструктуру в Docker: `docker compose up -d`
2. Переконайтесь, що ваш старий файл бази лежить за шляхом `data/school_testing.db`.
3. Запустіть скрипт міграції:
   ```bash
   python scripts/migrate_sqlite_to_postgres.py
   ```
   Скрипт автоматично прочитає дані зі SQLite та безпечно перенесе їх у PostgreSQL у контейнері.
