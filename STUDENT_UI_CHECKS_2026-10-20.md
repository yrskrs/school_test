# SchoolTest 1.6.10 — тема, масштаб і стан мережі

## Проблеми та виконаний план

1. Усунути перенесення літер у лічильниках. Причина — `overflow-wrap: anywhere` і занадто вузькі flex-елементи. Тепер сітка має мінімальну ширину комірки, підписи не розриваються, «Залишилось» скорочено до «Залишок».
2. Обмежити масштаб: 80–120%, крок 10%, скидання до 100%. Старі збережені значення автоматично обмежуються; крайні кнопки вимикаються. Геометрію перевірено при всіх трьох контрольних масштабах 80/100/120%.
3. Узгодити варіанти відповідей із темою. CSS `color-scheme: dark light` дозволяв браузеру залишати стандартні radio/checkbox темними при світлій темі сайту. Тепер схема явно відповідає обраній темі; фон варіантів також використовує палітру сайту.
4. Прибрати ручну перевірку мережі. У верхній панелі є кольоровий текстовий індикатор: з’єднання, доступний сервер, надсилання, відновлення, відсутність зв’язку, помилка збереження. Крапка пульсує для перехідних станів і втрати мережі; `prefers-reduced-motion` вимикає анімацію. Текст дублюється на блокувальних екранах. Виявлення HTTP 5xx тепер працює і під час фонового опитування.
5. Уточнити збереження. Підтверджені відповіді записані в БД сервера. Вибір до «Відповісти» — чернетка; серверний прогрес зберігає її окремо від оцінюваної відповіді. Локальний JSON — резерв для ручної перевірки, без імпорту в сесію або автоматичної зміни оцінки. Це прямо зазначено на підсумку й у `USER_GUIDE.md`.

## Перевірки

- Python: **142** тести застосунку та **22** тести `school_sync`, успішно.
- JavaScript: **27** сценаріїв учня, перевірка синтаксису **8** скриптів; перевірки моніторингу — один heartbeat після 20 перепідключень і один запит для 50 одночасних оновлень.
- Chromium: **136** перевірок розміщення сторінок учня й 11 сторінок учителя, екрани до 320 px, масштаби 80/100/120%. Перевірено обмеження старих 60/150%, відсутність перенесення підписів, тему при обох системних темах, збереження обраної відповіді, роботу без localStorage та завершення 25 питань із банку 200.
- Стабільність: **8** груп перевірок. Три реальні виходи з fullscreen, зупинка вчителем, відхилена чернетка та втрачена відповідь сервера про зупинку, третє попередження офлайн, незмінність обох таймерів офлайн, автоматичне відновлення після 503, збереження паузи вчителя та вимкнення анімації при зменшенні руху.
- Серверне підтвердження перевірено реальним HTTP/PostgreSQL: POST записує відповідь, учитель бачить її в моніторингу, але перший HTTP-відгук учневі навмисно губиться. До повтору браузер має 0 підтверджень і 1 запит у резерві. Автоповтор повертає `already_saved`, після чого браузер має рівно 1 підтвердження та переходить далі. Остаточні записи БД перевірено окремо.
- Області зображень і перетягування: **8** груп геометричних перевірок при прямому CSS zoom 60/80/100/150%; ці технічні масштаби не є дозволеними значеннями кнопок інтерфейсу.
- Штатна перевірка PostgreSQL: драйвери, HTTP, повідомлення, оновлення старої схеми та SQLite → PostgreSQL — успішно.

Браузерні сценарії завершилися без помилок JavaScript та native alert/dialog. Докази й знімки: [reports/student_ui_2026-10-20](reports/student_ui_2026-10-20). Візуально перевірено світлу й темну тему. Тестові дані використовували лише `tests/compose.runtime.yaml`: тимчасову PostgreSQL без робочих томів, `.env` чи відкритих портів. Допоміжне скидання display-сценаріїв тепер обмежено власним синтетичним учителем.

## Поведінка мережі та межі перевірки

При втраті зв’язку із сервером тест призупиняється, редагування блокується, обидва таймери зупиняються. Перевірки відновлення виконуються автоматично кожні 3 секунди; здоровий стан використовує наявне опитування кожні 5 секунд та початкову перевірку стану. Окремий індикатор не створює додаткового таймера чи каналу опитування. Відновлення не скасовує паузу вчителя або остаточну зупинку.

Повне проходження без зв’язку із сервером і імпорт локальних відповідей не додавалися. Відсутність інтернету не заважає роботі, коли локальний сервер доступний у шкільній мережі. Правила оцінювання, остаточність підтверджених відповідей і схема БД не змінені. Перевірено Chromium; Firefox/Safari та тривале навантаження окремо не перевірялися.
