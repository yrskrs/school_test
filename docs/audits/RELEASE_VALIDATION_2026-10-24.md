## Перевірки та збереження даних

- Фінальна 1.6.16: 158 тестів успішно на SQLite та PostgreSQL 16.
- Моніторинг 1.6.15: 127 браузерних перевірок; після розгортання й десяти
  HTTP-оновлень зміщення прокручування 0 px, зайвих переміщень рядків 0.
  Перевірено також згортання, фокус і сторінку результатів.
- Chromium, 1366 і 390 px: автоматичне заповнення паралелі / літери,
  доступ учня до списку за еквівалентною назвою; помилок JavaScript немає.
- Резервування: 16 тестів успішно, включно з початковою маскою 022 та
  каталогом 0755; підсумкові права копії 0700 / 0600.
- Резервні копії реально відновлено в тимчасовій PostgreSQL без мережі,
  опублікованих портів і робочих томів. Контейнер перевірки видалено.
- Установлений застосунок healthy, HTTP 200. Файли вкладень, таблиці
  учнів, тестів, сесій, спроб і відповідей мають однакові контрольні суми
  до та після робіт. Історичні сесії зі спробами не переприв'язувалися.

Перевірка робочих списків порівнювала знеособлені одноразові HMAC сталих ID,
без експорту ПІБ чи ID учнів. Непідтверджені додаткові записи не видалялися.
Дампи, cookie, ключі, реальні роботи та приватні звіти не входять до комітів.
