# SchoolTest 1.8.1 — резервування лише через Nextcloud

## Зміна

З резервування прибрано Google Drive, його поля ключів, OAuth-кнопку та callback. Доступний Nextcloud. Прямі запити й застарілі Google-завдання блокуються до звернення в мережу; старі Google-розклади вимикаються. Ядро цієї політики однакове зі SchoolWork 4.7.2.

Збережено особисті й адміністративні копії, ZIP, інкрементальні блоки, пароль, розклад, пошук, перевірку та відновлення. Наявні дані тестування, історія й архіви не видаляються. Міграцій БД немає. Старий Google-профіль потребує явного збереження підключення Nextcloud; Google-ключі не показуються в HTML/status API й прибираються під час збереження Nextcloud.

## Перевірка

Локально пройшли 35 тестів ядра, транспорту й стабільних блоків записів. Окремі сценарії HTTP перевіряють відсутність Google-контролів, callback 404, відхилення save/oauth/connect, приховування старих ключів і збереження Nextcloud. Тест повного відновлення посилено порівнянням усіх експортованих записів до/після відновлення.

У кандидатному Docker-образі всі 25 модулів застосунку запускалися окремими процесами з власними синтетичними SQLite, без робочих томів і мережі. Разом із school_sync пройшли **242 тести у 26 незалежних запусках**. Окремо **8 сценаріїв графа/HTTP** пройшли на ізольованому PostgreSQL 16; перевірено особисте й повне відновлення, ізоляцію, відповіді учнів, переносний ZIP із паролем та HTTP/CSRF. PostgreSQL-контейнер, його тестовий том і мережу після перевірок видалено.

## Установлення

SchoolTest **1.8.1** установлено на `192.168.1.13:8000`. Образ `schooltest5-app:1.8.1-nextcloud-only`; ревізія коду образу `38827d157a9b78fa43f85e6268a3c931ee5bac72`. Образ і серверні вихідні файли звірені за SHA-256 для всіх прикладних, тестових і службових файлів випуску. Застосунок healthy; публічний health повертає HTTP 200 і версію 1.8.1.

Перед оновленням перевірено відсутність активних недавніх спроб учнів, застосунок зупинено, створено узгоджену штатну копію PostgreSQL та файлових томів із перевіркою маніфесту/контрольних сум. Окремо збережено конфігурацію, керівну SQLite резервування, попередні змінені файли й образ для відкату. Вісім основних таблиць і всі **88 файлів** прикладних каталогів збігаються за кількостями й SHA-256 до/після встановлення. Робочі дані не були ціллю тестового відновлення.

Приватний аудит:
`/home/yrsadmin/school_test/backups/nextcloud-only-20261101-_ft5xx9z`.

Захисна копія даних:
`/home/yrsadmin/school_test/backups/nextcloud-only-20261101-_ft5xx9z/data`.

Обидві встановлені сторінки резервування перевірені з чинним адміністратором без створення нового сеансу входу: HTTP 200, доступні лише поля Nextcloud, Google-ключі відсутні в HTML/status API. Google callback видалений, Google-транспорт блокується, старі Google-розклади вимкнені. Наявні архіви й історія не видалялися. Міграцій БД немає.
