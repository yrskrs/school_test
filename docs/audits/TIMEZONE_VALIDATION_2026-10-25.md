# 1.7.2 — час здачі за Києвом

У результатах, моніторингу, деталях, HTML та CSV час був UTC без позначення поясу. Усі ці представлення тепер переводять збережений час у Europe/Kyiv за датою події. API передає явний offset UTC. Завершення в живому моніторингу береться з серверного запису, а не годинника вчителя; браузер також явно використовує Europe/Kyiv.

Історичні naive-поля не зміщуються. Нові записи використовують LEGACY_RESULT_TIMEZONE (типово UTC) незалежно від TZ контейнера. Архівування й календарні фільтри трактують вибрані дні за Києвом. Тривалість спроб залишається у вихідній системі зберігання.

Перевірено: повний набір unittest — 166 успішних перевірок на ізольованій SQLite; переходи UTC+3/UTC+2, повторення години восени, перехід календарної дати, старий пояс, контейнер Honolulu, сторінки результатів і API. JavaScript: моніторинг за Києвом при TZ=Pacific/Honolulu; перевірка 20 перепідключень і 50 паралельних оновлень — OK. Приватні дані не використовувалися в тестах.

Первинний аудит робочої БД: 236 спроб, 227 завершених; усі 227 мають подію завершення із розбіжністю меншою 0.062 секунди. Це перевірка узгодженості серверних записів, а не незалежний доказ історичної точності годинника. Час здачі означає приймання сервером, а не натискання кнопки при відсутності мережі.
